La propiedad max-width

Define el ancho máximo de un elemento. Evita que el elemento sea más ancho que el valor especificado (puede ser más angosto, pero no más ancho). Es muy útil para crear diseños responsivos y asegurar la legibilidad del contenido en distintos tamaños de pantalla.

El problema con width

Si la ventana del navegador es más pequeña que el ancho definido, parte del contenido no se verá bien, o el navegador agregará una barra de scroll horizontal.

Este elemento div tiene width: 500px.

Usando max-width en su lugar

Mejora el comportamiento en ventanas pequeñas:

Este elemento div tiene max-width: 500px.

Consejo: reduce el ancho de la ventana del navegador a menos de 500px para ver la diferencia entre ambos divs.
