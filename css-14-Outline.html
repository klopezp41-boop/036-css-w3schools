¿Qué es un outline?

Un outline es una línea dibujada alrededor de un elemento, POR FUERA de los bordes, para hacer que el elemento resalte:

Este elemento tiene un borde negro y un outline verde de 10px.

El outline se diferencia del border: se dibuja fuera del borde del elemento y puede sobreponerse a otro contenido. Además, el outline NO forma parte de las dimensiones del elemento, así que no afecta su ancho ni alto total.

Propiedades de outline: outline-style, outline-color, outline-width, outline-offset, y la abreviada outline.

outline-style

Define el estilo del contorno. No funciona ninguna otra propiedad de outline si esta no está definida:

outline-width

Define el ancho del contorno: thin (~1px), medium (~3px), thick (~5px), o un valor específico:

Un outline mediano.

Un outline grueso.

Un outline de 8px.

outline-color

Define el color del contorno: por nombre, HEX, RGB, HSL, o con el valor "invert" (que invierte el color para garantizar visibilidad):

Un outline sólido rojo.

Un outline punteado azul.

Un outline "outset" verde.

Un outline sólido invertido.

Propiedad abreviada outline

Permite definir outline-width, outline-style (obligatorio) y outline-color en una sola declaración, en cualquier orden:

Un outline discontinuo.

Un outline punteado rojo.

Un outline sólido amarillo de 7px.

Un outline grueso "ridge" rosado.

Outline con esquinas redondeadas

El outline también puede tener esquinas redondeadas, usando border-radius:
