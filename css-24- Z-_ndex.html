¿Qué es z-index?

Especifica el orden de apilamiento de elementos posicionados: define cuál se muestra delante o detrás de otros cuando se sobreponen. Puede tener un valor positivo o negativo.

Nota: z-index solo funciona en elementos posicionados (position: absolute, relative, fixed o sticky) y en elementos hijos directos de un contenedor flex.

Como la imagen tiene z-index: -1, se coloca detrás del texto.

Ejemplo con z-index definido

Un elemento con mayor z-index siempre se muestra por encima de uno con menor z-index:

Caja negra (z-index: 1)
Caja gris (z-index: 3)
Caja verde (z-index: 2)

Sin z-index definido

Si varios elementos posicionados se sobreponen sin z-index especificado, se muestran en el orden en que aparecen en el código HTML:

Caja negra
Caja gris
Caja verde
