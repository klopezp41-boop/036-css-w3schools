La propiedad overflow

Controla qué pasa con el contenido que es muy grande para el área que lo contiene: si se recorta o se agregan barras de scroll. Valores: visible (por defecto), hidden, scroll, auto.

overflow-x y overflow-y

Permiten controlar el desborde de forma independiente para cada dirección: overflow-x afecta los bordes izquierdo/derecho, y overflow-y los bordes superior/inferior.

Casos de uso comunes

Tablas anchas con scroll horizontal (overflow-x: auto), ventanas de chat con scroll vertical (overflow-y: scroll), y bloques de código con líneas largas (overflow-x: auto).
