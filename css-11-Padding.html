Padding básico

El padding genera espacio alrededor del contenido de un elemento, dentro de cualquier borde definido:

Este elemento tiene un padding de 70px.

Padding por lado individual

Se pueden definir valores distintos con padding-top, padding-right, padding-bottom y padding-left. Los valores pueden ser una medida (px, cm, etc), un porcentaje, o inherit. A diferencia de margin, no se permiten valores negativos.

Este div tiene padding superior de 50px, derecho de 30px, inferior de 50px, e izquierdo de 80px.

Propiedad abreviada padding

Permite definir los 4 valores de padding en una sola declaración.

Con 4 valores (arriba, derecha, abajo, izquierda)

padding: 25px 50px 75px 100px;

Con 3 valores (arriba, laterales, abajo)

padding: 25px 50px 75px;

Con 2 valores (arriba/abajo, laterales)

padding: 25px 50px;

Con 1 valor (los 4 lados iguales)

padding: 25px;

Padding y el ancho del elemento

La propiedad width especifica el ancho del área de contenido. Si un elemento tiene un ancho definido, el padding se suma a ese ancho total, lo cual muchas veces no es lo deseado:

Este div mide 300px de ancho.

El ancho real de este div es 350px, aunque en el CSS se definió como 300px (300px + 25px de padding izquierdo + 25px de padding derecho).

Padding y box-sizing

La propiedad box-sizing define cómo se calculan el ancho y alto de un elemento: si incluyen o no el padding y el borde.

  • content-box - valor por defecto. Width y height incluyen solo el contenido (sin padding ni borde)
  • border-box - width y height incluyen contenido, padding y borde

Usando box-sizing: border-box, el ancho se mantiene fijo sin importar cuánto padding se agregue:

Este div mide 300px de ancho.

El ancho de este div se mantiene en 300px, a pesar de los 50px totales de padding izquierdo y derecho, gracias a box-sizing: border-box.
