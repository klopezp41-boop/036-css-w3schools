¿Qué es un pseudo-elemento?

Es una palabra clave que se agrega a un selector para estilizar una parte específica de un elemento. Se usa para: estilizar la primera letra/línea, insertar contenido antes o después, estilizar marcadores de listas, el texto seleccionado por el usuario, o el fondo detrás de un cuadro de diálogo.

Sintaxis: selector::nombre-pseudo-elemento { propiedades }

  • De texto: ::first-line, ::first-letter
  • De contenido: ::before, ::after, ::marker, ::selection, ::backdrop
