Formas de insertar CSS

Existen tres maneras de insertar una hoja de estilos:

  • CSS externo - enlazando un archivo .css externo
  • CSS interno - usando el elemento <style> en la sección head
  • CSS en línea (inline) - usando el atributo style en el elemento HTML

CSS externo

Con una hoja de estilos externa se puede cambiar el aspecto de todo un sitio web modificando un solo archivo. Cada página debe incluir una referencia al archivo .css dentro del elemento <link>, en la sección <head>. Así se vería:

<link rel="stylesheet" href="mystyle.css">

Y el contenido del archivo "mystyle.css" sería algo así (un archivo CSS nunca debe contener etiquetas HTML):

body {
  background-color: lightblue;
}

h1 {
  color: navy;
  margin-left: 20px;
}

Nota importante: no se debe dejar espacio entre el valor de la propiedad y su unidad. Ejemplo incorrecto: margin-left: 20 px; — correcto: margin-left: 20px;.

Se puede usar un estilo en línea para aplicar un estilo único a un solo elemento. Se agrega el atributo style directamente al elemento, y puede contener cualquier propiedad CSS.
