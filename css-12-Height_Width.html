Alto y ancho básicos

Las propiedades height y width se usan para definir el alto y ancho de un elemento. No incluyen el padding, borde ni margen: definen el área dentro de ellos.

Este div tiene un alto de 70 píxeles y un ancho del 100%.

Valores posibles

  • auto - valor por defecto, el navegador calcula el tamaño
  • length - define el tamaño en px, cm, em, etc.
  • % - define el tamaño en porcentaje del contenedor
  • initial - restablece al valor por defecto
  • inherit - hereda el valor del elemento padre

Ancho mínimo y máximo (min/max-width)

La propiedad max-width define el ancho máximo permitido de un elemento, evitando que sea más ancho que ese valor. Útil para que la página se comporte mejor en ventanas pequeñas (evita el scroll horizontal).

width vs max-width

Achica la ventana del navegador para ver la diferencia: el div con width fijo no se reduce, mientras que el de max-width sí se adapta:
