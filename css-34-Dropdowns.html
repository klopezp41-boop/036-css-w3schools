¿Qué es un dropdown en CSS?

Se usa para mostrar una lista de opciones o contenido cuando el usuario hace clic o pasa el mouse sobre un elemento (el "trigger"), como un botón o enlace. El contenido desplegable vive en un contenedor (por ejemplo un div) que está oculto por defecto.

La clase contenedora usa position:relative, y el contenido desplegable usa position:absolute. Se usa box-shadow en vez de border para que se vea como una "tarjeta", y :hover para mostrarlo.
