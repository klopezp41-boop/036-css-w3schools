Sintaxis de CSS

Una regla de CSS consiste en un selector y un bloque de declaración. Por ejemplo, en este archivo, todos los elementos <p> están centrados y con texto en color rojo

Ejemplo explicado

  • p es un selector en CSS (apunta al elemento HTML que se quiere estilizar: <p>)
  • color es una propiedad, y red es el valor de esa propiedad
  • text-align es una propiedad, y center es el valor de esa propiedad
