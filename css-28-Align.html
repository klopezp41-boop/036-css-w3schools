Centrar elementos con CSS

Existen varios métodos para centrar elementos (horizontal, vertical, o ambos), dependiendo del tipo de elemento:

Estoy centrado vertical y horizontalmente.

  • Horizontal: margin: auto (bloques), text-align: center (texto), float o position (izquierda/derecha)
  • Vertical: Flexbox (align-items: center), Grid (place-items: center), o position + transform

Flexbox es el método más moderno y recomendado para centrar contenido en ambos ejes.
