¿Qué es la propiedad display?

Controla si un elemento se trata como bloque o en línea. Todo elemento HTML tiene un valor por defecto (block o inline), y la propiedad display permite cambiar ese comportamiento.

  • Elementos de bloque - siempre inician en nueva línea y ocupan todo el ancho disponible. Ejemplos: <div>, <h1>-<h6>, <p>, <form>
  • Elementos en línea - no inician en nueva línea, ocupan solo el ancho necesario. Ejemplos: <span>, <a>, <img>

Valores comunes de display

ValorDescripción
inlineMuestra el elemento en línea
blockMuestra el elemento como bloque
flexContenedor flex de nivel de bloque
gridContenedor grid de nivel de bloque
inline-blockEn línea, pero acepta width, height, padding y margin
noneEl elemento se oculta por completo, sin ocupar espacio

Nota: cambiar el display de un elemento no cambia qué tipo de elemento es. Un elemento en línea con display:block no puede tener otros elementos de bloque dentro.

display:none vs visibility:hidden

visibility:hidden oculta el elemento, pero sigue ocupando espacio en el diseño. display:none lo elimina del flujo del documento, sin ocupar ningún espacio.
