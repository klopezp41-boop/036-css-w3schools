¿Qué es una pseudo-clase?

Es una palabra clave que se agrega a un selector para definir un estilo según un estado especial de un elemento. Se usa para: estilizar al pasar el mouse, diferenciar enlaces visitados/no visitados, estilizar al enfocar un campo, validar formularios, o seleccionar el primer hijo de un elemento.

Sintaxis: selector:nombre-pseudo-clase { propiedades }

  • Interactivas: :hover, :focus, :active, :link, :visited
  • Estructurales: :first-child, :last-child, :nth-child(n), :lang()
