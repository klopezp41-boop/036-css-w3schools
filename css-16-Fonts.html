La importancia de elegir la fuente correcta

Elegir la fuente adecuada tiene un gran impacto en la experiencia de lectura del sitio. Es importante que sea legible, y elegir bien color y tamaño.

La propiedad font-family

Define la fuente de un elemento. Debe incluir varias fuentes como sistema de respaldo (fallback), separadas por comas, terminando siempre con una familia genérica. Si el nombre tiene más de una palabra, va entre comillas.

Familias genéricas de fuentes

Existen 5 familias genéricas: serif (con remates, elegantes), sans-serif (líneas limpias, modernas), monospace (ancho fijo, look mecánico), cursive (imitan escritura a mano) y fantasy (decorativas).

Google Fonts

Si no quieres usar las fuentes estándar de HTML, puedes usar Google Fonts: son gratuitas y hay más de 1000 para elegir. Se agregan enlazando una hoja de estilos en el head y luego usando el nombre de la fuente en font-family. Ejemplo de cómo se vería (requiere conexión a internet para cargar la fuente real):

<link rel="stylesheet" href="https://fonts.googleapis.com/css?family=Sofia">

body {
  font-family: "Sofia", sans-serif;
}

Para usar varias fuentes de Google a la vez, se separan con el carácter pipe (|): family=Sofia|Trirong|Audiowide. Ten cuidado, ya que pedir muchas fuentes puede hacer más lenta la página.

Buenas combinaciones de fuentes (Font Pairing)

Reglas básicas: elegir fuentes que se complementen (ni muy iguales ni muy distintas), usar "superfamilias" de fuentes diseñadas para combinar bien, aprovechar el contraste (por ejemplo serif con sans-serif), y definir una fuente "jefe" con tamaño/peso/color distintivo.

Propiedad abreviada font (shorthand)

Permite definir font-style, font-variant, font-weight, font-size, line-height y font-family en una sola declaración. font-size y font-family son obligatorios; si se usa line-height, va justo después de font-size separado por "/"; font-family siempre va al final.
