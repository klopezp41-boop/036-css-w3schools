La propiedad float

Especifica cómo debe flotar un elemento dentro de su contenedor, colocándolo a la izquierda o derecha y permitiendo que el texto lo rodee. Valores: left, right, none (por defecto), inherit. Se usa mucho para que el texto rodee imágenes.

La propiedad clear

Especifica qué pasa con el elemento que sigue a uno flotante. Evita que el contenido rodee un elemento flotado. Valores: none (por defecto), left, right, both, inherit.

Sin clear

Solución flexible con Flexbox

Flexbox ajusta automáticamente la altura de las cajas para que coincidan con la más alta, sin necesitar una altura fija:
