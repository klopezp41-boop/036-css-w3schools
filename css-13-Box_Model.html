¿Qué es el modelo de caja?

En CSS, "modelo de caja" se refiere al diseño de una caja que envuelve cada elemento HTML. Toda caja consta de cuatro partes, de adentro hacia afuera:

  • Content (contenido) - donde aparece el texto o las imágenes
  • Padding - despeja un área alrededor del contenido, es transparente
  • Border (borde) - rodea el padding y el contenido
  • Margin (margen) - despeja un área fuera del borde, también transparente

Ancho y alto de un elemento

Importante: al definir width y height con CSS, solo se está definiendo el tamaño del área de contenido. Para calcular el ancho y alto total del elemento, hay que sumar también el padding y el borde.

Ejemplo de cálculo

El ancho total de este elemento es de 350px, y el alto total es de 80px.

Cálculo del ancho: 320px (contenido) + 20px (padding izq+der) + 10px (borde izq+der) = 350px total.

Cálculo del alto: 50px (contenido) + 20px (padding sup+inf) + 10px (borde sup+inf) = 80px total.

Fórmula general:

Ancho total = width + padding izquierdo + padding derecho + borde izquierdo + borde derecho
Alto total = height + padding superior + padding inferior + borde superior + borde inferior

Nota: el margin también afecta el espacio total que ocupa la caja en la página, pero no se incluye en el tamaño real de la caja — el ancho y alto totales terminan en el borde.
