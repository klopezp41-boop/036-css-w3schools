¿Qué es el posicionamiento en CSS?

El posicionamiento en CSS permite controlar la ubicación de los elementos en la página, incluso anulando el flujo normal del documento. La propiedad position puede tener los valores: static (por defecto), relative, fixed, absolute y sticky. Se combina con top, bottom, left y right para definir la ubicación final.

position: static

Es el valor por defecto de todos los elementos. No se ve afectado por top, bottom, left ni right, y se posiciona según el flujo normal de la página:

Este elemento div tiene position: static;

position: relative

Se posiciona en relación a su posición normal. Al usar top/right/bottom/left, se desplaza desde ahí, pero el espacio original que ocupaba no se rellena con otro contenido:

Este div tiene position: relative, y está desplazado 30px a la derecha de su posición normal.

position: fixed

Se posiciona en relación al viewport, así que siempre queda en el mismo lugar aunque se haga scroll. No deja un espacio vacío donde estaría normalmente. (Aquí se simula dentro de un contenedor para no afectar el resto del archivo):

position: absolute

Se posiciona en relación al ancestro más cercano que tenga una posición distinta de static. Se elimina del flujo normal del documento y puede sobreponerse a otros elementos:

position: sticky

Alterna entre relative y fixed según la posición del scroll: se queda "pegado" cuando llega a la posición indicada (aquí, top: 0). Se requiere definir al menos uno de top/right/bottom/left. Haz scroll dentro del recuadro para ver el efecto:
